# SELENE — bougies naturelles

Prototype de boutique en ligne pour **SELENE**, marque de bougies 100 % cire végétale coulées à la main, sous le signe de Séléné, déesse grecque de la Lune.

Site statique (HTML/CSS/JS) hébergé sur GitHub Pages : brume animée en WebGL, défilement doux (Lenis), transitions voilées.

- Boutique avec filtres et tri, pages produit, panier persistant (localStorage)
- Commande avec paiement **simulé** (carte test `4242 4242 4242 4242`, refus simulé avec `4000 0000 0000 0002`)
- Code promo caché : touchez trois fois la lune de l'accueil…
- Oracle « Quel parfum es-tu ? » en tirage de cartes, légende de Séléné

Photos : Unsplash & Pexels — crédits détaillés sur la page `#/credits` du site.
